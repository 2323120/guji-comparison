# 古籍版本比对工具

这是一个可以直接部署到 GitHub Pages 的古籍版本比对网页。适合没有代码基础的使用者维护：整个网站主要只有一个 `index.html` 文件。

## 主要功能

- 上传古籍图片、PDF，或直接输入文本
- 单个文件限制 200MB
- 最多加入 6 个版本
- 免费 OCR：使用 Tesseract.js，在浏览器中识别
- 自定义 OCR API：可接入你自己的 OCR 服务
- OCR 后逐页校核：左侧看原图，右侧改文字
- 多版本文本比对：相似度矩阵、并排对照、差异高亮
- 导出识别文本和比对报告

## 使用方法

1. 打开网页。
2. 在左侧选择“图片”“PDF”或“文本”。
3. 填写版本名称，例如“明刻本”“清抄本”“校勘底本”。
4. 上传文件或粘贴文本，点击“加入版本列表”。
5. 如果有图片或 PDF，点击“开始 OCR”。
6. OCR 完成后，可以点击“逐页校核”修改识别结果。
7. 点击“生成比对结果”，查看各版本差异。
8. 点击“导出文本与报告”，保存研究材料。

## GitHub Pages 部署

1. 进入本仓库的 Settings。
2. 找到 Pages。
3. Source 选择 `Deploy from a branch`。
4. Branch 选择 `main`，目录选择 `/ (root)`。
5. 保存后等待 1 到 3 分钟。
6. 打开 GitHub Pages 给出的链接即可使用。

## 注意事项

- 免费 OCR 首次加载较慢，需要联网下载 OCR 组件。
- 古籍繁体、异体字、模糊影印件的识别结果一定要人工校核。
- GitHub Pages 是静态网页，适合低成本原型；如果以后要保存用户账户、云端文件、多人协作，需要再加后端服务。
- 自定义 OCR API 需要对方服务允许浏览器跨域访问，否则会被浏览器拦截。
