古籍版本比对工具

上传图片、PDF，或直接输入文本。系统可先做 OCR，再逐页人工校核，最后最多选择 6 个版本进行文本比对。

单文件不超过 200MB 最多 6 个版本 浏览器本地处理为主 支持自定义 OCR API

1. 新增版本

图片支持 JPG、PNG、WebP。PDF 会自动逐页转成图片后识别。

2. OCR 设置

免费 OCR 不需要账号，但古籍繁体、异体字、版刻模糊时需要人工校核。自定义 API 适合接入你自己购买或申请的 OCR 服务。

本工具会向 API 发送 JSON：{ fileName, mimeType, imageBase64 }，并在 Authorization 请求头中放入 API Key。

建议流程：先加入多个版本，再点“开始 OCR”。文本版本会直接进入比对，不需要 OCR。
